# Sistem Perpustakaan Digital

Pengelolaan koleksi buku, anggota, peminjaman, pengembalian dan stok.

## Fitur Wajib

1. CRUD buku dan kategori
2. Data anggota
3. Pencarian buku
4. Peminjaman
5. Pengembalian
6. Monitoring stok
7. Laporan perpustakaan

## Jenis Pengguna

1. Petugas
2. Anggota

## Aturan Bisnis

1. Tidak boleh meminjam buku dengan stok habis
2. Peminjaman mengurangi stok tersedia
3. Pengembalian memperbarui stok
4. Pengembalian ganda harus dicegah
